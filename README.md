# host-tur3l

NixOS on WSL configuration for host `tur3l` (software lab environment).

## Repository Overview

- `flake.nix`: Main Nix Flake defining NixOS WSL system and Home Manager integrations
- `config.nix`: NixOS system configuration (WSL settings, user setup, Docker, fish, packages)
- `shell.nix`: Nix development shell
